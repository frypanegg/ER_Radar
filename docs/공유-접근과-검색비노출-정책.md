# 공유 접근과 검색 비노출 정책

이 서비스는 로그인 없이 **공유 URL을 받은 사람**이 열람하는 방식으로 운영한다. 공개 로그인 페이지나 계정 생성 과정은 두지 않는다.

## 적용한 비노출 조치

- 모든 HTML 응답에 `X-Robots-Tag: noindex, nofollow, noarchive, nosnippet, noimageindex`를 설정한다.
- 페이지 메타데이터에 `noindex`, `nofollow`, `noarchive`, `nosnippet`, `noimageindex`, `nocache`를 설정한다.
- `robots.txt`에서 모든 크롤러의 전체 경로 수집을 차단한다.
- 소셜 미리보기용 Open Graph·X 카드 메타데이터를 제공하지 않는다.

## 보안 경계

위 설정은 일반 검색엔진과 미리보기 수집기의 노출을 줄이는 **비색인 정책**이다. URL을 아는 사람이 접속하는 것을 기술적으로 막지는 않는다. URL 유출까지 차단해야 하는 경우에는 별도의 비밀번호 또는 인증 계층이 필요하다.

## 운영 확인

- 배포 후 응답 헤더와 HTML 메타태그를 확인한다.
- 검색 결과에서 이미 색인된 적이 있다면 각 검색엔진의 삭제 도구를 별도로 요청한다.
- 링크를 외부 공개 게시물·검색 가능한 문서에 싣지 않는다.
