### 이 파일을 읽을 때 걸리는 함정

`KEY = value` 형식이다(등호 양옆 공백). 셸 `source`로 읽히지 않고
`startsWith("KEY=")` 매칭도 실패한다. **반드시 등호로 split 후 양쪽을 strip한다.**
실제로 이걸 놓쳐 빈 시크릿을 등록해 메일 발송이 조용히 건너뛰어진 적이 있다.

```python
for line in open(path, encoding="utf8"):
    s = line.strip()
    if not s or s.startswith("#") or "=" not in s: continue
    k, v = s.split("=", 1)
    env[k.strip()] = v.strip()
```

### 그 밖의 주의

- **`service_role` 키는 RLS를 우회한다.** 서버·로컬에서만 쓰고 브라우저·`NEXT_PUBLIC_`·
  정적 파일·로그에 넣지 않는다. 비밀값은 화면에 출력하지 않고 길이·존재 여부만 보고한다.
- `wrangler secret put`은 리다이렉트 설정을 읽지 않는다. **`--name er-radar`가 필요하다.**
  이걸 몰라 예약 실행이 실패한 적이 있다.
- `SUPABASE_URL`이 `kkj.env`에는 `SUPABASE_PJT_URL`로 들어 있다. 적재기는 두 이름을 모두 받는다.

## 6. 이 프로젝트에서 실제로 밟은 함정들

같은 실수를 반복하지 않기 위한 목록이다. 전부 겪은 것이다.

| 영역 | 함정 |
| --- | --- |
| PostgREST | 업서트 충돌 대상은 **쿼리 파라미터** `on_conflict`다. 헤더로 보내면 무시되고 중복 키 오류가 난다 |
| Supabase 공개 게이트 | `is_published`는 `include_in_primary_dashboard`까지 켜져 있어야 통과한다 |
| Supabase 스키마 | `coverage_tier`는 `CORE/EXPANDED/WATCH`, `sources.source_type`은 `NEWS`다 |
| `sources` RLS | anon 정책이 `source_annotations` 연결을 요구한다. 연결을 안 만들면 anon에 출처가 0건이다 |
| GitHub schedule | 보장이 아니다. 실제로 유실됐다. 예비 스케줄 3회 + 지연 감시로 대응했다 |
| 예약 실행 | 사람이 없으면 첫 권한 프롬프트에서 멈춘다. 미리 승인해 두지 않으면 아무것도 못 한다 |
| 단계 정렬 | 같은 날 두 사건이면 **단계 순위로 갈라야** 한다(가결과 조인식이 같은 날인 경우) |
| 단계 하강 | 파업 기사가 교착(S4)을 본교섭(S3)으로 내릴 수 있다. 명시적 근거 없으면 막는다 |
| 가결 ≠ 체결 | `임단협 가결`이 조인·체결과 같은 신호로 묶여 S7로 올라가던 버그가 있었다 |
| 파업 찬반투표 | 제목 뒤의 "임단협" 때문에 인준(S6)으로 읽히던 버그가 있었다 |
| 경과 중복 제거 | `sourceUrl`만으로 묶으면 한 기사가 전체 일정을 요약한 경우 1건만 남는다. `url+date+stage`로 본다 |
| DART 서식명 | 공시 제목에 `파업`은 없다. `생산중단`·`풍문또는보도에대한해명`을 찾아야 한다 |
| 화면 상태 유지 | 연도·필터를 바꿀 때 선택한 법인을 유지해야 한다. `companyId`로 이어붙인다 |

## 7. 절대 바꾸지 말 것

- **사실은 제목이나 회사명만으로 추정하지 않는다.** 원문 URL·확인일·직접고용 범위 근거·
  출처 등급을 함께 보존한다.
- **기사·공시 본문을 복제·저장하지 않는다.** 제목·매체·발행일·URL과 계산된 분류만 남긴다.
  메일 본문도 같은 경계를 지킨다.
- **하청·간접고용 사례는 원청 상대 교섭이라도 공개 대시보드에 섞지 않는다.**
- **`S6`을 `S7`로 올리려면 조합원 가결이 아니라 서명·조인·발효 근거가 필요하다.**
- **수정은 접수와 공개를 분리한다.** 사람이 제출한 수정도 `PENDING`으로만 들어가고,
  근거 URL·사유·수정자가 없으면 접수하지 않는다.
- **근거가 없으면 빈 칸으로 둔다.** 값이 없는 항목을 그럴듯하게 채우지 않는다.
- 이 파이프라인은 **LLM을 호출하지 않는다.** 분류·범위 판정·단계 승격은 전부 규칙 기반이다.
